# Лабораторная работа 2

**Тема:** Наивный байесовский классификатор (Naive Bayes)

В этой работе:
- Проведён анализ датасета Mushroom из UCI, вычислено распределение категориальных признаков по классам.
- Построены решающие правила на основе одного признака, определена их информативность.
- Использован наивный байесовский классификатор из sklearn и реализован вручную с регуляризацией Лапласа.
- Результаты сравниваются, дополнительно оценивается метод логистической регрессии с вероятностными признаками.
